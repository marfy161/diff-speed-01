A faster drop-in replacement for makefun-diff 1.0.0. It produces byte-identical diff patches (same header, hunks, and line prefixes) with lower CPU time — verified 100% identical on the practice set and ~2.4% faster than the baseline on average (2340ms vs 2397ms over 5 runs each).

## Run it

```sh
node main.ts
```
